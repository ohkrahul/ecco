# ECCO India — "Walk Your Walk" pitch microsite

Slide-by-slide pitch site: 23 full-screen slides, no scrolling. Vite + GSAP (SplitText) + Three.js.
Design: `../docs/2026-11-25-microsite-design.md` · Plan: `../docs/2026-11-25-microsite-plan.md`

## Run it

```bash
npm install          # once
npm run dev          # while editing → http://localhost:5173
npm run build        # production build into dist/
npm run preview      # serve dist/ → http://localhost:4173   ← use this in the pitch room
```

**Pitch room:** `npm run build` beforehand, then `npm run preview` on the presenting laptop and open
http://localhost:4173 full-screen (F11). Everything (fonts, 3D model, images, video) is bundled — no internet needed.

### Presenting slide by slide (next to the deck)

The microsite follows the deck **in the same order, one screen per slide**, plus two "campaign flow" slides that show
how each route runs as a launch: **23 slides**. One clicker press, key, mouse-wheel notch or trackpad swipe = one slide;
each slide's animation plays by itself when it arrives. Three slides have a second click, like a PowerPoint build:
**And ECCO?** on the category wall, the **manifesto** on the zone, and the **end frame** of The Unseen Hours.

→ / ↓ / PageDown / Space / Enter = next, ← / ↑ / PageUp / Backspace = back (builds reverse first), Home = first,
End = last. F5 always restarts at slide 1. The counter bottom-right shows `07 / 23 · label · Deck slide 9 · click 1/2`
so the microsite and the PPT stay in step; it shows automatically on localhost (or with `?present`), **P** hides/shows it.

## Check it

```bash
npm run preview      # in one terminal
npm run smoke        # in another: clicks through every slide and build in Edge at 1440 and 1920 px,
                     # screenshots each into shots/, fails on JS errors, 404s, external requests,
                     # a stuck preloader, text cut off by the screen edge, or the 3D shoe on the wrong slide.
                     # Also: back through builds, header links, one trackpad flick = one slide,
                     # the film dialog, F5 → slide 1, ?nowebgl and reduced motion.
```

Options: `WIDTHS=1440 SKIP_PERF=1 npm run smoke`.

## Confirm with the client before the pitch

- The five USPs on the x-ray slide use the deck's wording (comfort, Danish make, end to end, contemporary design, made for walking).
- The campaign-flow phasing and week numbers are **our proposal** (indicative) — add matching slides to the PPT if you keep them.
- Not for publication: the Unseen Hours poster shows Ajay Devgn and Smriti Mandhana likenesses, slide 7 shows competitor campaigns, slide 16 names real people.

- `<meta name="robots" content="noindex">` is set. Don't share a public link without the client's OK.

## Where things live

- `index.html` — all copy and slide markup (content is readable without JS).
- `src/styles/tokens.css` — colour plan, type scale. `src/styles/deck.css` — layout, one screen per slide.
- `src/deck.js` — the slide engine: input, glide between slides, builds, header, presenter HUD.
  A slide's motion is `slide(id, (tl, el) => …)`: fill the paused timeline `tl`; each label in it is a click.
- `src/stage.js` — the single Three.js canvas (shoe, x-ray cut, fallback). Slides drive it via `stage.show()` / `stage.hide()`.
- `src/sections/*.js` — each slide's entrance and builds.

## Deploying

`vercel.json` (repo root) builds `microsite/` and serves `microsite/dist`.
